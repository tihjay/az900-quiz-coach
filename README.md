# AZ-900 Practice Tool

An unofficial, browser-based practice quiz tool designed to help learners prepare for the Microsoft Azure Fundamentals (AZ-900) certification exam. The tool presents topic-based quizzes with instant feedback and detailed explanations to reinforce key Azure concepts.

## Features

- **Topic-based quizzes** — Questions organized into core AZ-900 domains: Cloud Concepts, Azure Architecture, Azure Services, and Security & Governance.
- **One question at a time** — Focused, single-question format with multiple-choice answers.
- **Instant feedback** — Immediately see whether your selected answer is correct, along with a detailed explanation.
- **Score tracking** — A live score counter and progress bar keep you informed throughout the quiz.
- **Results screen** — View your final score, percentage, total questions answered, and personalized feedback based on your performance:
  - **90–100%**: Excellent readiness for AZ-900
  - **70–89%**: Good understanding, review weaker topics
  - **Below 70%**: More study recommended before taking the exam
- **Answer review** — After completing a quiz, review every question with your answer, the correct answer, and the explanation.
- **Restart quiz** — Retake any topic quiz to reinforce your knowledge.

## Technologies Used

- **React** — UI library for building interactive components
- **TypeScript** — Type-safe development
- **Vite** — Fast build tool and development server
- **Tailwind CSS** — Utility-first styling framework
- **Lucide React** — Icon library

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open your browser to the URL shown in the terminal (typically `http://localhost:5173`).

5. To create a production build:

   ```bash
   npm run build
   ```
